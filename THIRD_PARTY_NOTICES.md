## Open-Meteo

Weather data is provided by Open-Meteo (https://open-meteo.com) and is licensed under CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/). Mutemark shows an attribution link to Open-Meteo wherever weather is displayed. Open-Meteo is only contacted while the weather widget is on and you have chosen a place (or are searching for one), see PRIVACY.md.

## Fonts

The interface font is Inter, version 4.1, by Rasmus Andersson and the Inter Project Authors. The variable font file `InterVariable.ttf` from the release is converted to WOFF2 without other changes and ships as `src/fonts/InterVariable.woff2`. It is loaded from the extension package, nothing is downloaded. The full license text ships next to it as `src/fonts/OFL.txt`.
